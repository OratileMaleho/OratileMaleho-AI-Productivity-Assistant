# Jesus Is King

A modern, responsive AI workplace productivity assistant built with TanStack Start, React, and Tailwind CSS. The app features **Tido**, a rhyming AI chatbot, alongside an AI Task Planner and AI Research Assistant to help professionals automate daily workplace tasks.

![Jesus Is King](public/og-image.png)

## Features

- **Tido — Rhyming AI Chatbot**
  Ask Tido anything and receive practical, responsible AI advice written as rhyming verse. Tido is powered by the Lovable AI Gateway (Google Gemini) and remembers your conversation history.

- **AI Task Planner**
  Generate structured task plans from an objective, role, timeframe, and constraints. Edit, save, and delete plans in a clean markdown editor.

- **AI Research Assistant**
  Create research briefs on any topic with configurable depth (Quick scan, Standard, Deep dive). Outputs are editable and persist to your account.

- **Modern Dashboard**
  See at-a-glance stats, quick-access tool cards, and recent activity across plans and briefs.

- **Responsive Design**
  A purple-themed, professional SaaS-style UI that works on desktop, tablet, and mobile.

- **Authentication**
  Secure sign-up and sign-in via email/password or Google OAuth, backed by Lovable Cloud.

## Getting Started

### Prerequisites

- Node.js 20+
- A Lovable Cloud project with Supabase enabled
- A Lovable API key (for AI Gateway access)

### Installation

```bash
# Clone the repository
git clone <repository-url>
cd <repository-name>

# Install dependencies
npm install

# Start the development server
npm run dev
```

The dev server runs at `http://localhost:8080`.

### Environment Variables

Create a `.env` file in the project root with the following variables:

```env
VITE_SUPABASE_URL=<your-supabase-url>
VITE_SUPABASE_PUBLISHABLE_KEY=<your-supabase-anon-key>
LOVABLE_API_KEY=<your-lovable-api-key>
```
